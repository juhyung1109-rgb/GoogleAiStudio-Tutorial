# 🎬 AI 유튜브 검색기 (AI YouTube Searcher)

> **유튜브 영상 링크 하나로 고화질 시청부터 오디오 추출, 음성 전사(STT), AI 3줄 핵심 요약, 스마트 타임라인 챕터 생성, 문맥 기반 대본 탐색 및 대화형 Q&A까지 제공하는 종합 AI 비디오 어시스턴트 웹 서비스입니다.**

---

## 🌟 주요 핵심 기능

### 1. 🔍 유튜브 영상 즉시 로딩 & 커스텀 UI
- **유튜브 스타일 상단 헤더**: YouTube 로고(`KR` 뱃지)와 중앙 URL 검색창 배치 (마이크, 만들기, 알림 등 불필요한 요소 제거).
- **YouTube IFrame API 플레이어**: 링크 입력 즉시 동영상 메타데이터(제목, 채널명, 재생 시간)와 함께 고화질 영상 재생.
- **음향 크기(볼륨) 정밀 제어**: 0~100% 실시간 볼륨 슬라이더 및 원클릭 음소거(Mute) 토글 버튼 지원.

### 2. ⚡ Gemini 3.5 Transcribe 정밀 음성 전사 (STT)
- **오디오 자동 추출**: `yt-dlp`를 활용해 원본 영상에서 고품질 오디오를 안전하게 추출.
- **단어 오프셋 정밀 추적**: `gemini-3.5-transcribe`의 `word_timestamp`와 화자 분리(Diarization)를 통해 초 단위 발화 시점을 정밀 파악.

### 3. 📖 문맥 연결 단락(Contextual Paragraph) 기반 전체 대본
- **지능형 문맥 단락화**: 단순 문장 분할로 인한 파편화나 거대한 덩어리 묶음을 방지하고, 하나의 이야기와 주제가 이어지는 **3~5개 연관 문장(약 15~35초 분량) 단위의 자연스러운 문맥 단락**으로 자동 결합.
- **화자 및 주제 전환 포착**: 앵커, 기자, 시민 인터뷰 등 발화자가 바뀌거나 새로운 주제로 넘어가는 시점을 정밀하게 구분하여 단락 생성.
- **원클릭 점프 재생 & 실시간 하이라이트**: 대본을 클릭하면 해당 구간으로 영상이 즉시 이동하며, 영상 재생 시점에 맞춰 현재 대본이 자동으로 하이라이트되고 자동 스크롤됩니다.

### 4. ✨ Gemini 3.8 Flash 기반 AI 3줄 핵심 요약
- 전체 영상을 다 보지 않아도 **가장 중요한 핵심 3문장**을 추출하여 플레이어 하단에 요약 카드 형태로 표시합니다.
- 10초 만에 영상의 전체 핵심 맥락을 빠르게 파악할 수 있습니다.

### 5. 📑 스마트 타임라인 챕터 (목차) 자동 생성
- AI가 영상의 전개 과정을 논리적으로 분석하여 **3~6개의 주요 타임라인 챕터(시작 시간, 소제목, 1줄 설명)**를 자동 생성합니다.
- **원클릭 타임라인 점프**: 챕터 칩을 클릭하면 해당 시간으로 즉각 이동합니다.
- **실시간 싱크 활성화**: 영상이 재생됨에 따라 현재 재생 중인 구간의 챕터 칩이 자동으로 파란색 활성화(Active) 상태로 하이라이트됩니다.

### 6. 🔎 스마트 내용 검색 & 타임스탬프 탐색
- 영상에서 찾고 싶은 키워드나 문장(예: *"인정전"*, *"날씨 원인"*, *"고종"*)을 검색하면, 로컬 키워드 매칭과 Gemini 3.8 Flash 의미 분석을 통해 **해당 내용이 시작되는 가장 적절한 시간대로 자동 점프하여 재생**합니다.
- 검색창은 시청을 방해하지 않도록 사이드바 **`🔍 내용 검색`** 탭 내부에 깔끔하게 배치되어 있습니다.

### 7. 💬 Gemini 3.8 Flash 대화형 Q&A
- 영상 대본 전체를 기반으로 사용자의 질문에 대해 친절하고 정확하게 답변합니다.
- 답변 내에 증거가 되는 시간대를 `[MM:SS]` 형태의 인터랙티브 타임스탬프 링크로 제공하여, **답변 속 시간을 클릭하면 해당 영상 시점으로 즉각 이동**합니다.

### 8. 💾 CSV 파일 영구 저장 및 0초 즉시 캐시 (`transcripts.csv`)
- 한 번 분석된 영상의 트랜스크립트, 세부 세그먼트, 3줄 요약, 챕터 정보는 `transcripts.csv` 파일에 자동 저장됩니다.
- 동일한 링크를 다시 검색할 경우 **Gemini API 재호출 없이 0초 만에 즉시 로드**되어 비용과 시간을 대폭 절감합니다.
- Windows Excel에서도 한글 깨짐 없이 열리도록 `utf-8-sig` 인코딩을 적용했습니다.

## 🏗️ 시스템 아키텍처

```
ai_youtube_searcher/
├── app.py                      # FastAPI 메인 서버 애플리케이션 (라우트 및 파이프라인 제어)
├── requirements.txt            # Python 필수 패키지 목록
├── run.bat                     # Windows 원클릭 서버 실행 배치 파일
├── transcripts.csv             # 분석된 영상 대본, 3줄 요약, 챕터 영구 CSV 캐시 저장소
├── downloads/                  # 추출된 오디오(.m4a) 및 로컬 임시 캐시 폴더
├── services/                   # 백엔드 핵심 비즈니스 로직 모듈
│   ├── youtube.py              # 유튜브 URL 파싱, 메타데이터 조회, yt-dlp 오디오 다운로드
│   ├── transcriber.py          # Gemini 3.5 Transcribe STT & 단어 오프셋 정밀 파서
│   ├── searcher.py             # Gemini 3.8 Flash (3줄 요약, 챕터 생성, 문맥 단락화, Q&A, 타임스탬프 탐색)
│   └── csv_storage.py          # transcripts.csv 영구 저장 및 캐시 조회 모듈
└── static/                     # 프론트엔드 정적 웹 리소스
    ├── index.html              # YouTube 다크 모드 레이아웃 UI
    ├── css/
    │   └── style.css           # 반응형 레이아웃, 요약 카드, 챕터 칩, 다크 테마 스타일
    └── js/
        └── main.js             # YouTube Player API 연동, 실시간 싱크 트래커, Q&A 및 검색 이벤트
```

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 사용 기술 | 설명 |
| :--- | :--- | :--- |
| **Backend** | Python 3.11+, FastAPI, Uvicorn | 고성능 비동기 REST API 백엔드 |
| **AI Models** | `gemini-3.5-transcribe` | 오디오 단어 단위 타임스탬프 및 화자 분리 음성 전사 |
| | `gemini-3.8-flash` | 3줄 요약, 챕터 생성, 문맥 단락화, 의미 기반 탐색, 대화형 Q&A |
| **Media Tools** | `yt-dlp` | 유튜브 비디오 메타데이터 조회 및 오디오 스트림 추출 |
| **Frontend** | Vanilla JS, HTML5, CSS3 | YouTube Dark Theme 인터페이스 및 인터랙티브 위젯 |
| **Player API** | YouTube IFrame Player API | 외부 비디오 제어, 타임 점프(`seekTo`), 실시간 볼륨 조절 |
| **Storage** | CSV (`transcripts.csv`) | Excel 호환 UTF-8-SIG 영구 캐시 저장소 |

## 🚀 빠른 시작 (Getting Started)

### 1. 환경 설정 및 API 키 입력
프로젝트 루트 폴더(또는 상위 폴더)의 `.env` 파일에 Google Gemini API 키를 설정합니다:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### 2. 가상환경 및 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. 서버 실행
**방법 A: 원클릭 실행 (Windows)**
- `run.bat` 파일을 더블 클릭하여 실행합니다.

**방법 B: 콘솔에서 직접 실행**
```bash
# 가상환경 활성화 (예: Conda)
conda activate myenv

# uvicorn 서버 실행 (포트 8001)
python -m uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```

### 4. 서비스 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **[http://localhost:8001](http://localhost:8001)**

## 💡 사용 방법

1. **유튜브 링크 입력**: 상단 검색창에 유튜브 영상 링크(예: `https://youtu.be/...`)를 입력하고 검색 버튼을 누릅니다.
2. **즉시 시청**: 영상이 바로 로드되어 재생되며, 볼륨 슬라이더로 음향을 편하게 조절할 수 있습니다.
3. **AI 분석 자동 완료**: 백그라운드에서 오디오가 다운로드되고 Gemini 모델에 의해 분석됩니다.
4. **3줄 요약 & 챕터 확인**: 영상 하단에 생성된 핵심 3줄 요약을 읽고, 스마트 챕터 칩을 클릭하여 원하는 구간으로 빠르게 이동합니다.
5. **내용 검색 & 질의응답**:
   - `🔍 내용 검색` 탭: 특정 단어나 문장을 검색하여 해당 발화 시점으로 점프 재생합니다.
   - `💬 Gemini 3.8 Flash Q&A` 탭: 대화창에 영상에 관한 질문을 입력하고 타임스탬프 답변을 확인합니다.
   - `📜 전체 대본` 탭: 문맥 단위로 정리된 대본을 읽으며 원하는 단락을 클릭해 청취합니다.
