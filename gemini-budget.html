01왜 100만원이 위태로운가

부가세와 환율을 걷어내면 실제로 쓸 수 있는 돈은 생각보다 적습니다.

사업자등록번호가 없는 개인 명의 Google Cloud 계정은 부가세 10%가 별도 청구됩니다. 100만원을 부가세 포함 총액으로 보면 실사용 가능액은 909,091원, 2026년 9월 9일 환율(1,336원) 기준 약 $673입니다. 이 돈으로 4.5개월 동안 Gemini API + Firebase + Cloud Run + BigQuery + Storage를 전부 감당해야 합니다.

06구독이 대신해주지 않는 것

여기를 착각하면 예산이 그대로 샙니다.

경계선

개발 시간의 비용은 구독으로, 서비스 실행의 비용은 API 예산으로. 이 한 문장이 전부입니다.

학생이 에디터 앞에서 코드를 만들어내는 동안 발생하는 토큰은 구독이 먹습니다. 하지만 완성된 서비스가 배포된 뒤 사용자 요청을 받아 호출하는 Gemini API는 반드시 유료 API 키를 통해야 하고, 100% 예산에서 차감됩니다. 최종 프로젝트가 “LLM을 부르는 웹 서비스”라면 데모·부하 테스트 비용도 여기 포함됩니다.

  • Antigravity·CLI 한도는 공식 수치가 비공개이며 개인 사용 기준입니다. 에이전트를 병렬로 여러 개 돌리면 5시간 창을 금방 소진합니다. 순차 작업 위주로 쓰도록 지도해야 합니다.
  • Firebase·Cloud Run·BigQuery·Storage는 구독과 무관합니다. 인프라 12~22만원은 어떤 시나리오에서도 예산에서 나갑니다.
  • 구독 계정과 GCP 결제 계정은 별개입니다. 학생이 개인 Google 계정으로 구독하고, 프로젝트는 강의용 결제 계정에 붙는 구조를 미리 정리해두어야 합니다.
  • 2027년 1월 1일 Flash 단가 2배 인상은 구독으로 막을 수 없는 API 쪽 이슈입니다. 대량 배치 작업은 12월 안에 끝내는 편이 낫습니다.

07더 싸게 가는 길: 무료 혜택과 교육 크레딧

대학생 요금제, $300 무료 체험, 그리고 강사가 직접 신청하는 교육 크레딧.

만 18세 이상 대학생은 Google AI Plus를 12개월 무료로 받을 수 있습니다(신청 마감 2026년 12월 31일, 결제수단 등록 필요, 무료 기간 종료 후 월 7,500원 자동 청구). 사용량 한도는 무료 대비 2배, 저장용량 400GB입니다.

단, 중요한 차이

Antigravity의 상향 한도는 AI Pro 항목이지 Plus 항목이 아닙니다. 이 수업이 Antigravity 기반 바이브 코딩이라면 Plus 무료 혜택만으로는 부족합니다. 현실적인 조합은 이렇습니다.

  • 대학생 수강생 — Plus 12개월 무료를 먼저 신청해 Gemini 앱·자료 정리 트래픽을 덜어내고, Antigravity를 본격적으로 쓰는 프로젝트 구간(11월~1월)만 Pro로 3개월 결제 → 구독비 87,000원, Cloud 크레딧 $30 회수.
  • 고등학생 수강생 — 대학생 혜택 대상이 아닙니다. Pro 5개월 정가 결제를 기본으로 잡고, 결제수단이 없는 학생은 기관 계정 또는 강사 계정 공유 방식을 미리 정해야 합니다.
  • GCP 신규 계정 $300 무료 크레딧(90일) — 9월에 만들면 12월 초 만료입니다. 단, 이 크레딧으로는 AI Studio용 Gemini API를 결제할 수 없습니다. 반드시 Vertex AI 경로로 붙여야 하며, 방법은 08절에 정리했습니다.

학교 계정으로도 $300을 받을 수 있나

공식 자격 요건에 “교육용 계정 제외” 조항은 없습니다. 조건은 두 가지뿐입니다 — ① Google Cloud·Maps Platform·Firebase의 유료 사용자였던 적이 없을 것, ② 이전에 무료 체험에 가입한 적이 없을 것. 크레딧은 조직 단위가 아니라 사용자 단위라서, 같은 학교에서 여러 명이 각각 받을 수 있고 개인 신용카드로 신청해도 됩니다.

막히는 지점은 자격이 아니라 운영 쪽입니다.

  • 관리자가 Google Cloud를 꺼두었을 수 있습니다. 학교 Workspace 관리 콘솔에서 해당 서비스가 OFF면 로그인 단계에서 막힙니다. 교육용 계정에서 가장 흔한 실패 원인이므로, 수업 전에 학교 IT 담당자에게 확인하세요.
  • 신용카드가 본인 확인용으로 필요합니다. 청구는 없지만 등록은 해야 합니다. 미성년 수강생은 여기서 걸립니다.
  • 1인 1회입니다. 개인 계정으로 이미 받은 학생은 학교 계정으로 또 받을 수 없습니다.
  • 90일 후 소멸하고 이월되지 않습니다. 수업 시작에 맞춰 일괄 개설해야 낭비가 없습니다.

08$300 크레딧은 AI Studio 키로는 못 씁니다

같은 Gemini 모델이라도 어느 문으로 들어가느냐에 따라 크레딧 적용이 갈립니다.

Google Cloud 공식 문서에 명시된 문장입니다 — “$300 크레딧은 AI Studio의 Gemini API 비용을 결제할 수 없습니다.” AI Studio에서 발급한 API 키(generativelanguage.googleapis.com)로 호출하면, 결제 계정에 $300이 남아 있어도 그 금액은 건드리지 않고 카드에 그대로 청구됩니다. 실제로 2026년 3월 이후 개발자 포럼에는 같은 청구서에서 Vertex AI 요금은 크레딧으로 차감되고 Gemini API 요금만 카드로 결제된 사례가 반복 보고되고 있습니다.

답

네, 가능합니다 — 단 Vertex AI 경로로 붙였을 때만입니다. Gemini 모델 자체는 동일하고 토큰 단가도 사실상 같습니다. 바뀌는 것은 인증 방식(API 키 → 애플리케이션 기본 사용자 인증 정보)과 엔드포인트뿐이며, 컨텍스트 캐싱(입력 75% 절감)과 Batch(50% 할인)도 Vertex에서 그대로 쓸 수 있습니다.

“GCP에서 키를 발급하면 달라지나요?”

달라지지 않습니다. 크레딧 적용을 가르는 것은 키를 만든 위치가 아니라 호출하는 엔드포인트입니다. Cloud 콘솔의 사용자 인증 정보 화면에서 만든 키든 AI Studio에서 만든 키든, generativelanguage.googleapis.com을 부르는 순간 AI Studio Gemini API로 과금되고 $300 크레딧은 비껴갑니다. 모든 Gemini API 키는 어차피 Cloud 프로젝트에 묶여 있고, 그 프로젝트가 결제·할당량·권한을 관리합니다.

지출도 숨겨지지 않습니다. 표시 기준 역시 키 발급 위치가 아니라 키가 속한 프로젝트입니다. 같은 프로젝트라면 AI Studio의 Dashboard > Usage, Billing, Spend 페이지에 그대로 잡힙니다. 다른 프로젝트에서 만들었다면 AI Studio에서 그 프로젝트로 전환해야 보일 뿐입니다. Cloud Billing 보고서에도 함께 올라오지만 반영이 하루 이상 늦을 수 있어, 실시간에 가까운 확인은 AI Studio 쪽이 낫습니다.

지금 당장 주의

Cloud 콘솔에서 만드는 키는 “표준 키”이고, 2026년 9월부터 Gemini API가 이 요청을 거부합니다. 제한이 걸리지 않은 표준 키는 이미 차단되었습니다. AI Studio에서 만드는 새 키는 자동으로 서비스 계정에 묶인 인증(auth) 키로 생성되므로, 수강생에게는 Cloud 콘솔이 아니라 AI Studio에서 키를 발급받게 안내해야 합니다. 학기 중에 전원이 401을 맞는 사고를 막는 가장 간단한 조치입니다.

신규 계정 절차 변경

2026년 3월 23일부터 Gemini API 유료 전환에는 최소 $5의 선불(Prepay) 충전이 필요합니다. 그리고 AI Studio Spend 페이지에서 프로젝트별 지출 상한을 걸 수 있습니다 — 상한에 닿으면 해당 결제 계정에 연결된 모든 프로젝트의 서비스가 일시 중지되므로, 수강생 계정 폭주를 막는 가장 확실한 안전장치입니다. 참고로 AI Pro의 월 $10 크레딧처럼 Gemini API에 사용 가능한 Cloud 크레딧은 선불 잔액보다 먼저 소진됩니다.

수강생 세팅 절차

  1. 프로젝트를 만들고 Vertex AI API를 켠다gcloud projects create → gcloud config set project → gcloud services enable aiplatform.googleapis.com. 결제 계정에 $300 크레딧이 붙어 있는지 콘솔에서 확인합니다.
  2. API 키 대신 ADC로 로그인한다gcloud auth application-default login. 그다음 unset GEMINI_API_KEY, unset GOOGLE_API_KEY — 키가 남아 있으면 SDK가 조용히 AI Studio 경로로 되돌아가 크레딧을 비껴갑니다. 여기가 가장 많이 틀리는 지점입니다.
  3. 환경변수 3줄을 고정한다GOOGLE_GENAI_USE_VERTEXAI=true · GOOGLE_CLOUD_PROJECT=<프로젝트 ID> · GOOGLE_CLOUD_LOCATION=global. global로 두면 리전별 모델 가용성 문제를 피할 수 있습니다.
  4. SDK는 그대로, 초기화만 바꾼다@google/genai · google-genai 통합 SDK에서 vertexai: true와 project·location만 넘기면 됩니다. 모델명과 호출 코드는 동일합니다.
  5. Gemini CLI도 Vertex 모드로 돌린다Gemini CLI는 ① Google 로그인(구독 한도) ② API 키 ③ Vertex AI 세 가지 인증을 지원합니다. 위 환경변수를 설정하면 ③번으로 동작해 크레딧에서 차감됩니다. 다만 구독 한도로 쓰는 게 더 싸므로, 평소엔 ①번, 크레딧을 태울 때만 ③번으로 전환하는 편이 낫습니다.
  6. 배포 서비스는 서비스 계정으로Cloud Run·Vercel에 올릴 때는 roles/aiplatform.user 권한의 서비스 계정 키를 GOOGLE_APPLICATION_CREDENTIALS로 넘깁니다. 코드는 바꿀 필요가 없습니다.
타이밍

$300 크레딧은 90일 정액 만료입니다. 9월 중순에 계정을 만들면 12월 중순에 소멸하고, 남은 금액은 이월되지 않습니다. 중간 프로젝트(9~11월) 구간을 이 크레딧으로 태우고, 100만원 예산은 최종 프로젝트와 1월 발표 준비에 남겨두는 배분이 맞습니다. 체험 종료 후에는 30일 유예 기간 안에 유료 계정으로 전환해야 리소스가 살아 있습니다.

09강의 운영 체크리스트

첫 주에 이것만 세팅해두면 C 과다형은 발생하지 않습니다.

  1. 키는 AI Studio에서만 발급하게 한다Cloud 콘솔에서 만든 표준 키는 2026년 9월부터 거부됩니다. AI Studio 발급 키는 자동으로 인증(auth) 키이므로, 수강생 안내 문구를 발급 경로까지 못박아 둡니다.
  2. AI Studio Spend 페이지에 프로젝트별 상한을 건다Cloud Billing 예산 알림은 사후 통보일 뿐이지만, AI Studio의 지출 상한은 도달 시 서비스를 실제로 멈춥니다. 수강생 1인당 상한을 걸어두면 C 과다형 사고 자체가 발생하지 않습니다.
  3. 첫 실습 전에 Vertex AI 경로로 통일한다수강생 전원이 GOOGLE_GENAI_USE_VERTEXAI=true 환경에서 시작하도록 초기 세팅 스크립트를 배포합니다. AI Studio 키로 먼저 익숙해지면 $300 크레딧이 통째로 사장됩니다.
  4. 예산 알림과 할당량 상한을 먼저 건다Cloud Billing 예산 알림을 50 / 80 / 100%에 걸고, Gemini API 할당량에 일일 상한을 지정합니다. Tier 1은 10분당 $10까지 쓸 수 있으므로, 상한이 없으면 하룻밤 사이 예산이 사라질 수 있습니다.
  5. 모델 라우팅 규칙을 수업 규칙으로 못박는다기본은 Flash-Lite / Flash. 아키텍처 설계와 막힌 버그만 Pro. “일단 제일 좋은 모델” 습관이 B와 C를 가르는 가장 큰 변수입니다.
  6. 컨텍스트를 200K 아래로 유지시킨다Pro는 200K를 넘는 순간 입력 $2 → $4, 출력 $12 → $18로 뜁니다. 세션을 자주 끊고, 대화 이력 대신 AGENTS.md 같은 규칙 파일로 맥락을 전달하도록 훈련합니다.
  7. 컨텍스트 캐싱을 실습 과제로 넣는다캐시 적중률 75%면 Pro 입력 단가가 실질 $0.65까지 떨어집니다. A 절약형과 B 표준형의 격차 대부분이 여기서 나옵니다.
  8. 일괄 처리는 Batch API로수업자료 일괄 정리, 임베딩 생성처럼 즉시성이 필요 없는 작업은 Batch로 돌려 50% 할인을 받습니다.
  9. 검색 그라운딩은 월 5,000회 안에서초과하면 1,000회당 $14입니다. 위키 구축처럼 검색을 많이 부르는 작업은 월별로 나눠 배치합니다.
  10. 12월 말까지 Flash 대량 작업을 끝낸다2027년 1월 1일부터 Flash 단가가 2배입니다. 자료 일괄 정리·대량 요약은 12월 안에 마칩니다.
  11. Cloud for Education 크레딧을 이번 주에 신청한다심사에 최대 15영업일이 걸리고, 쿠폰은 강좌 시작일로부터 16주 이내에 수령해야 합니다. 지금 넣어야 최종 프로젝트 구간에 맞춰 도착합니다.
  12. 구독 도입 시점을 프로젝트 시작에 맞춘다지금 가입하면 5개월 145,000원, 11월부터면 3개월 87,000원입니다. 중간 프로젝트는 GCP $300 크레딧으로 덮고, 구독은 최종 프로젝트 구간에 집중시키는 편이 현금 효율이 좋습니다.
